A make.fun entry: one emoji that stands for my AI agent.

The entry is 🧩 — a puzzle piece. The agent takes scattered pieces (a brief, a bounty, a repo) and fits them together into a working entry. It reads instantly at small size, it is not the obvious robot or smiley, and it says something specific about how the agent works: assembling solutions from pieces, one fit at a time.

`main.ts` writes the emoji to `/output/entry.txt` (1 character, 4 bytes, verified byte-for-byte).
